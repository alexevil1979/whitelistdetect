Google Play — Data safety / App content (ответы)

Приложение собирает данные? Да, ограниченно, только для работы диагностики.
Продажа данных: нет
Шифрование в транзите: да (HTTPS)
Пользователь может запросить удаление: да — очистить историю / удалить приложение (всё локально)

Данные:
1. Приблизительное местоположение / диагностика — нет GPS. Страна/город только как ответ GeoIP-сервиса по публичному IP.
2. Идентификаторы устройства — нет рекламного ID.
3. Сетевая активность приложения — проверки выбранных сайтов (не логируем у себя).
4. IP-адрес — уходит к ipify, ipapi.co, ipinfo.io, ifconfig.co при GeoIP. Не хранится на наших серверах (серверов нет).

Сбор: приложение / не связано с аккаунтом.
Необязательно: GeoIP и фоновые проверки можно не использовать, основная проверка — по кнопке.

Разрешения в анкете Play:
• INTERNET, NETWORK_STATE, WIFI_STATE — функциональные
• POST_NOTIFICATIONS — статус-бар и опциональный результат
• FOREGROUND_SERVICE + DATA_SYNC — мониторинг раз в минуту, выключается в настройках
• RECEIVE_BOOT_COMPLETED — поднять индикатор после перезагрузки, если пользователь его включил
• VIBRATE — тактильный отклик

Foreground service: Data Sync
Обоснование: пользователь явно включает «значок в строке состояния»; сервис периодически синхронизирует вердикт доступности сайтов и обновляет уведомление. Не скрытый трекинг.
