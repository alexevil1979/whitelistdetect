# Whitelist Pulse

Диагностическое Android-приложение: измеряет текущее соединение и показывает, в каком режиме сейчас интернет. **Это не VPN и не инструмент обхода ограничений.**

Приложение не обходит блокировки, не содержит туннелей, прокси, DPI-обход и не выдаёт себя за сервис Минцифры, оператора или Роскомнадзора. Списки сайтов — неофициальная агрегация публичных данных на 2026 год и могут устареть.

## Что умеет

- Параллельные лёгкие HTTPS-проверки трёх контрольных групп (белый список / обычный рунет / зарубежные и ограниченные сервисы)
- Вердикт с пояснением: обычный интернет, похоже на белый список, нет сети, проверка через VPN, вне РФ или обход, нестабильность
- Карточка соединения: тип сети, VPN/туннель/прокси (только детекция), GeoIP, DNS, история, текстовый отчёт
- Пользовательские сайты, пресеты, виджет 2×2, плитка Quick Settings
- Русский интерфейс по умолчанию, английский — второй язык
- Без обязательных Play Services и без телеметрии: проверки с устройства, история только локально

## Сборка

Требования: JDK 17, Android SDK 35.

Windows:

```bat
gradlew.bat assembleDebug
gradlew.bat testDebugUnitTest
```

macOS / Linux:

```sh
chmod +x gradlew
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

Открыть папку в Android Studio и запустить конфигурацию `app`.

Идентификатор пакета: `ru.whitelist.pulse`  
minSdk 26 · targetSdk 35 · Kotlin 2.x · Jetpack Compose · Material 3 · Hilt

## Разрешения

- `INTERNET`
- `ACCESS_NETWORK_STATE`
- `ACCESS_WIFI_STATE`
- `POST_NOTIFICATIONS` — только если пользователь явно включает уведомления о результате или запускает проверку из плитки
- `VIBRATE` — тактильный отклик по завершении проверки

`QUERY_ALL_PACKAGES` не используется. Известные VPN-клиенты проверяются точечно через `getPackageInfo` и блок `<queries>` в манифесте. Список установленных приложений никуда не отправляется.

SSID Wi‑Fi может быть недоступен без разрешения на геолокацию — приложение его не запрашивает.

## Юридическое

Приложение — сетевой диагностический инструмент. Оно **не**:

- не встраивает VPN, прокси, SOCKS, Tun2Socks, обход DPI
- не даёт пошаговых инструкций по обходу блокировок
- не маскирует трафик
- не является официальным сервисом Минцифры / оператора / Роскомнадзора
